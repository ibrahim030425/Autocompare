# AutoCompare 🚗

AutoCompare is a modern car comparison web application built with React and TypeScript.

The goal of the project is to make it easier to explore different cars, compare specifications and save favorite vehicles in one place.

## Features

* Browse a collection of cars
* Search cars by brand or model
* Filter by brand, fuel type and price
* Sort cars by price, power and rating
* View detailed car specifications
* Compare up to 3 cars side by side
* Save favorite cars
* Responsive design
* Persistent favorites and comparisons using local storage

## Tech Stack

* React
* TypeScript
* Vite
* React Router
* Lucide React
* CSS
* Local Storage

## Getting Started

### Prerequisites

Make sure you have Node.js installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/ibrahim030425/Autocompare.git
```

Navigate to the project:

```bash
cd Autocompare
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.
